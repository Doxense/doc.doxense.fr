Haute-disponibilité

La haute-disponibilité (ou HA pour High Availability) est la qualité d'un système, ou d'une partie d'un système (un périphérique, par ex.), dont le pourcentage de temps d'utilisation est très élevé par rapport au temps global où il est en demande. (Source : OQLF)

 

La haute-disponibilité de Watchdoc repose sur la surveillance du Service Watchdoc et du spooler MS Windows® ainsi que sur la sécurisation de la connectivité entre le poste de travail et le serveur d'impression,, mais aussi entre le périphérique d'impression et le serveur d'impression.

 

La haute-disponibilité des WES englobe 3 modes différents*.

  • Le mode multiserveur : ce mode permet d'associer un ou des serveurs de secours au serveur d'impression principal. Ces serveurs de secours sont ainsi capables de traiter les requêtes en cas de panne du serveur principal.

    Ce mode n'est pas compatible avec tous les modèles de périphériques (fonctionne avec les WES développés en Java). Il doit être configuré sur le profil WES installé sur le périphérique (cf. Configurer leprofil WES, section > options de secours).

     

  • Le mode tolérance de pannes : ce mode rend le WES compatible avec un équipement réseau qui gère la répartition de charge (load-balancing). Paramétré avec l'équipement qui gère le load-balancing, le WES ne connaît pas précisément les serveurs d'impression.

    La fonction est activée par défaut sur les WES compatibles (WES Java). Sur certains de ces WES, il est possible de la désactiver.

     

  • Le mode hors-ligne : ce mode rend le périphérique d'impression capable de fonctionner de manière dégradée dans le cas où les serveurs d'impression (principal et de secours) sont en panne. En mode hors-ligne, l'impression est impossible, mais les autres fonctions du périphérique telles que la photocopie, le fax et le scan peuvent être proposées.

    En cas de panne des serveurs, si le mode hors-ligne est désactivé, toutes les fonctions du périphérique sont bloquées jusqu'à dépannage du serveur.

    Ce mode est configuré dans le profil WES installé sur le périphérique (cf. Configurer leprofil WES, section > options de secours).

 

* ces modes ne sont pas compatibles avec tous les modèles. Rendez-vous dans la page Fonctionnalités de votre WES pour vérifier.
