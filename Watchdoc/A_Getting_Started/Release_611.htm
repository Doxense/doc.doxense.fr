  • La mise à jour vers Watchdoc v 6.1.1 5654 nécessite l'installation de MS dotnet-hosting-10.0.9-win.exe sur le site qui héberge le site web.
  • Watchdoc v. 6.1 nécessite une nouvelle licence, qui inclut la licence WSC (formulaire de demande de licence à adresser à l'équipe Support via le site Connect). 
  • WSC v. 6.1 requiert la réinstallation à l'aide de DriverPackageExtractor des pilotes installés dans des versions antérieures
  • Watchdoc v. 6.1 requiert la version 4.8 du MS .NET Framework (à télécharger ici).
  • Watchdoc v. 6.1 requiert Microsoft Visual C++ 2013 (à télécharger ici).
  • Nous ne recommandons pas l'utilisation de l'authentification par code PUK. En conséquence, depuis la version 6.1.0.5273, ce mode d'authentification est désactivé par défaut lors de la configuration d'un annuaire. Cette désactivation n'a aucune incidence en cas de mise à jour depuis une version où ce mode d'authentification est déjà configuré.
  • Nous ne recommandons pas l'installation en mode déporté (serveurs web IIS et Watchdoc différents). En conséquence, entre les versions 6.1.0.5221 et 6.1.0.5318, le port 5744 est automatiquement fermé et doit être configuré (cf. Configurer le port 5744).

Watchdoc et WSC 6.1.1.5745, WPC for Windows 7.0.6156 et Skyprint 7.0.6155 - 23/09/2026

Amélioration

  • WPC for Android et iOS: amélioration graphique du menu d'édition des documents

 

Correctifs

  • Watchdoc :

    • correction des opérations d'interopérabilité entre les versions N et N-1 pour faciliter la mise à jour vers v 6.1.1, même lorsque l'on commence la migration par un serveur slave (ce qui n'est pas recommandé).

    • la fonction de suppression de la configuration d’une file est désormais opérationnelle : la configuration est désormais définitivement supprimée et n’est plus archivée comme file externe comme auparavant

    • après migration de la configuration Watchdoc d'un serveur vers un autre, une anomalie perturbait l’impression interserveur. Désormais, ce cas est correctement pris en charge et l'impression interserveur fonctionne.

    • en Configuration avancée, dans le tableau du diagnostic serveur, les libellés longs n'étaient pas affichés intégralement. Désormais, les libellés longs s'affichent intégralement.

  • WES Xerox : correction d'une anomalie empêchant la comptabilisation des impressions (et débit des quotas) via le WES lorsque la fonction "Secure-print" est activée sur le pilote d'impression (cf. Configurer le profil WES Xerox - Section Quota).

  • WEScan : dans le cas où un utilisateur n’avait pas le droit d’utiliser la destination de scan configurée par défaut, le bouton "Destination" restait vide. Désormais, une autre destination est proposée à l'utilisateur. Par défaut, il s’agit de la dernière destination qu’il a utilisée.

Watchdoc et WSC 6.1.1.5732, WPC for Windows et Skyprint 7.0.6152 - 10/09/2026

Watchdoc Express / Watchdoc Setup  / Watchdoc Update / WSC Setup / WSC Update 

Améliorations

  • Watchdoc : amélioration du délai de redémarrage du Service Watchdoc.

  • WES Canon :

    • depuis la configuration du WES Canon, ajout d’un bouton permettant un accès distant à l’écran d’administration (remote panel) du périphérique

    • en cas d’erreur lors de l’installation du WES sur le périphérique d’impression, le message d’erreur a été corrigé

    • dans le cas d’un pilote CPCA/PCL-XL avec IPP désactivé sur la file, la seule option de transformation disponible est la conversion en recto-verso. La correction permet de ne plus afficher la suggestion de transformation lorsqu’un travail ne fait qu’une page.

  • WPC for Android et iOS : optimisation du temps de soumission pour les fichiers volumineux.

Correctifs

  • Watchdoc : un avertissement déconseillant le partage du périphérique de sortie s'affichait sur toutes les files, même lorsqu'aucun partage n'était configuré. Ce message ne s’affiche plus.

  • WPC : correction d'une anomalie de détection des emplacements lorsqu'une adresse IP se situe entre deux plages de sous-réseaux disjointes.

  • WES : en configuration d’un WES, si le périphérique était en SSL et que l’on activait l’option multiserveur, le port non-sécurisé. (Unsecured Port) était rempli automatiquement avec la valeur 5754 à la validation du formulaire si l'administrateur avait laissé le champ vide. Ce comportement a été modifié : s’il n’est pas rempli par l’administrateur, le champ reste vide.

  • WES Kyocera : correction d'une anomalie qui empêchait la détection de l'URI IPP lors de l'installation d'une file d'impression Kyocera.

Watchdoc et WSC 6.1.1.5717, WPC for Windows et Skyprint 7.0.6152 - 26/08/2026

Watchdoc Express / Watchdoc Setup  / Watchdoc Update / WSC Setup / WSC Update 

Nouvelle fonctionnalité

  • Watchdoc : ajout d'une fonction de migration d'une file réseau partagée installée par GPO sur un poste utilisateur lors du déploiement de WPC for Windows. La fonction supprime également les anciennes files installées comme files réseau partagées (cf. Configurer WPC for Windows).

 

Améliorations

  • Watchdoc : amélioration de la configuration des emplacements dans WPC for Windows. Un emplacement "parent" ne pouvait pas être sélectionné. Désormais, un emplacement parent est sélectionnable si les paramètres Utilisateurs et Appareils sont cochés (cf. Configurer les emplacements).
  • WES : amélioration de l'interface de personnalisation des couleurs des WES (colorpicker) pour l'ensemble des WES.
  • WES Canon : test de nouveaux périphériques compatibles.
  • WPC for Windows :
    • simplification lors d'un changement d'emplacement : lors du passage sur un nouvel emplacement, celui-ci est désormais sélectionné automatiquement sans demande de confirmation. Il reste modifiable manuellemen depuis l'onglet des emplacements

    • files d'impression mémorisées : les files installées manuellement sur un emplacement sont maintenant conservées et automatiquement réinstallées au retour sur cet emplacement, même après une déconnexion ou un redémarrage du poste

    • fenêtre d'authentification moins intrusive :elle ne se rouvre plus automatiquement après une coupure réseau ou VPN temporaire. Elle continue de s'afficher normalement au démarrage, depuis la barre des tâches ou lors d'une demande d'impression non-authentifiée

    • tutoriel désactivable : les administrateurs peuvent désormais désactiver globalement l'affichage du tutoriel du client Windows depuis l'administration Watchdoc. L'option reste activée par défaut pour ne pas modifier le comportement existant (cf. Configurer WPC for Windows)

 

Correctifs

  • Watchdoc :

    • correction d'un blocage survenant lors de l'installation : le prérequis "hosting bundle" bloquait le processus. Il est désormais de nouveau possible d'installer Watchdoc en kernel seul sans service IIS

    • correction de la configuration du pilote d'une file universelle : lorsque la plateforme "Mobile" était sélectionnée, il n'était plus possible de sélectionner un pilote. Désormais, quelle que soit la plateforme sélectionnée (tags supportés), il est possible de sélectionner un pilote

    • correction d'un dysfonctionnement lié à l'apparition d'un processus inconnu PDFConvert lors d'une impression LPD

    • correction des pools de travaux clonés sur les serveurs slaves : il n'est plus possible de modifier une configuration sur un serveur slave. La modification n'est possible que depuis le serveur master

  • WPC for Windows :

    • amélioration des opérations de désinstallation :la suppression d'une file déjà supprimée manuellement ou refusée par Windows ne bloque plus l'application. Un message d'erreur explicite s'affiche désormais lorsque la suppression échoue.
