Comparatif Page de déblocage / Mon compte V1 /vs/ Mon compte V2

Contexte

Watchdoc propose une nouvelle version de la page web dédiée aux utilisateurs de Watchdoc
Remplaçant les pages web "Déblocage des impressions" et "Mon compte", cette interface, appelée "Mon compte v. 2" dans l'administration, est désormais unique pour l'utilisateur. Il y retrouve les informations et données d'impression qui le concernent.

Certificats

Par défaut, le port 5753 est sécurisé par un certificat auto-signé. 

Pour plus de sécurité, nous vous recommandons de faire signer ce certificat par votre autorité de certification. 
Idem si vous choisissez un port dédié autre que le 5753, qui aura tout intérêt à être sécurisé par un certificat signé par votre autorité de certification.
