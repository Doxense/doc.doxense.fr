Watchdoc - Profil de déblocage web - Page Mon compte v. 2 - Prérequis

Principe

La page Mon Compte v. 2 est automatiquement installée à partir de Watchdoc v. 6.1.1.5654.

Pour activer la page Mon Compte v. 2, les prérequis suivants doivent être respectés.

Flux et ports

Flux entre Page de déblocage /
 Mon Compte v. 1		 Page Mon Compte v. 2
Poste de travail IIS 443 443
IIS Watchdoc Service 5744 non-concernée
Poste de travail Watchdoc service non-concernée • 5753 en cas d'installation initiale
• ou 5753 en cas de mise à jour, mais avec risque d'avoir à réinstaller les WES dotés d'un certificat ;
• ou port dédié (par exemple 5759) en cas de mise à jour pour éviter d'avoir à réinstaller les WES si c'est trop contraignant.

Certificats

Par défaut, le port 5753 est sécurisé par un certificat auto-signé.

Pour plus de sécurité, nous vous recommandons de faire signer ce certificat par votre autorité de certification.

Vous pouvez aussi choisir un port dédié autre que le 5753 (5759, par exemple). Ce port aura tout intérêt à être sécurisé par un certificat signé par votre Autorité de Certification (cf. Gérer les certificats - Faire signer un certificat pour Watchdoc).

 

Exécutables

La page Mon compte v. 2 requiert les outils suivants sur le site qui héberge le service IIS :

  • MS URL Rewrite (cf. Microsoft IIS downloads page) ;

  • pour l'authentification MS Windows, l'exécutable MS dotnet-hosting-10.0.9-win.exe.

 

Lors d'une installation initiale de Watchdoc, ces outils sont installés automatiquement.

Lors d'une mise à jour de Watchdoc, il est nécessaire d'installer ces outils au préalable. Si ce n'est pas le cas, l'assistant de mise à jour affiche un message d'information.
