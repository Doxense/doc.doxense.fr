Watchdoc Print Client for iOS® - Utiliser

Principe

Watchdoc Print Client for iOS® est une application professionnelle mise à disposition par votre organisation sur son portail AppleStore®.
Elle vous permet d'imprimer des documents PDF à partir de votre mobile iOS.
Une fois le travail d'impression envoyé, vous vous rendez sur le périphérique d'impression (imprimante ou MFP) de votre choix pour débloquer (valider) vos impressions.

Accéder à l'application

Pour accéder à Watchdoc Print Client for iOS, cliquez sur l'icone installée sur votre mobile.
S'il s'agit d'un mobile personnel utilisé dans un cadre professionnel, l'icone figure dans l'espace professionnel de votre mobile.

N.B. : si l'icone n'y figure pas, contactez la personne en charge des applications mobiles de votre organisation pour savoir comment activer l'app. sur votre mobile.

S'identifier

  1. Pour utiliser l'application, vous devez vous identifier à l'aide de votre compte.
    Il s'agit du compte enregistré dans l'annuaire paramétré par défaut dans Watchdoc ou un compte invité créé dans la base Invités de WSC.
    Si votre compte est enregistré dans un annuaire MS Azure et que le SSO est activé, vous pouvez aussi cliquer sur Me connecter avec [Nom_Entreprise] :

è Si le serveur de découverte n'est pas accessible, un message vous en informe. Dans ce cas, vous ne pouvez pas vous authentifier.
è En cas d'identifiant erroné, le message "Echec de connexion" vous en informe.


  1. Un message de bienvenue confirme votre identification et vous informe de la nécessité de sélectionner un emplacement. Cet emplacement permet à l'application de trouver les périphériques (imprimantes ou MFP) sur lesquels vous pouvez physiquement récupérer vos impressions.

  1. cliquez sur J'ai compris pour accéder à l'outil :


Sélectionner l'emplacement

Par défaut, Watchdoc Print Client for iOS propose un emplacement correspondant à l'adresse IP à partir de laquelle votre mobile se connecte au réseau.

Dans la liste Emplacement s'affichent les lieux dotés d'imprimantes réseau sur lesquelles vous êtes susceptibles de récupérer vos impressions.

  1. Vérifiez l'emplacement affiché et conservez-le s'il correspond au lieu depuis lequel vous souhaitez imprimer ;

  2. si vous voulez en changer :

    1. utilisez le moteur de recherche pour retrouver l'emplacement à l'aide de son nom ;

    2. ou parcourez la liste pour y sélectionner l'emplacement, puis confirmez votre sélection ;

     

    N.B. : si un emplacement est grisé, c'est qu'il ne dispose pas d'imprimante ou de serveur d'impression opérationnel et qu'il ne peut donc pas être utilisé temporairement.

     

  3. Lors de la première utilisation, une fois l'emplacement sélectionné, vous êtes invité à autoriser l'accès aux fichiers de votre mobile iOS :

Lancer l'impression depuis Watchdoc Print Client for iOS

Après avoir autorisé l'accès aux fichiers, vous accédez à l'interface d'impression :

  1. cliquez sur le bouton Sélectionner un document  ;

  2. parcourez les fichiers PDF enregistrés dans votre mobile et sélectionnez le document . que vous souhaitez imprimer :
    è     le nom du document s'affiche dans le champ de sélection :

    N.B. : si vous n'arrivez pas à sélectionner certains documents dans votre mobile (titre du document grisé), c'est qu'il ne s'agit pas de documents PDF.

     

  3. cliquez ensuite sur le bouton Sélectionnez une destination ;

  4. dans la liste Destinations, cherchez et sélectionnez l'imprimante vers laquelle vous souhaitez envoyer votre travail d'impression :


    è le nom de l'imprimante choisie s'affiche dans le champ de sélection :



  5. si nécessaire (et si le périphérique d'impression le permet), modifiez les Options de finition :

  6. cliquez sur le bouton Imprimer :
    (N.B. : si vous ne souhaitez finalement pas imprimer le document sélectionné, vous pouvez quitter l'application ou sélectionner un autre document à imprimer).

    1. si Watchdoc est en mode "comptabilisation", le document est imprimé sans nécessiter de déblocage. Vous pouvez donc vous rendre sur l'imprimante sélectionnée pour y récupérer votre impression :

       

    2. si Watchdoc est en mode "validation", un message vous informe que la soumission est réussie : le document a bien été envoyé à l'imprimante. 


       

      èVous pouvez alors vous rendre près de l'imprimante de votre choix, puis dans l'interface Travaux en attente de l'application pour débloquer votre impression (cf. Débloquer l'impression).

Lancer l'impression depuis la fonction "partager le document .pdf"

Watchdoc Print Client for iOS vous permet de lancer l'impression depuis la fonction "Partager le document .pdf" de votre mobile.

  1. Dans votre mobile, sélectionnez le fichier PDF que vous souhaitez imprimer ;

  2. dans la liste des actions, cliquez sur le bouton Partager (Share)  :


  3. dans la liste d'applications permettant le partage, sélectionnez l'application Watchdoc Client :

  4. identifiez-vous dans l'interface Watchdoc. 

  5. Sélectionnez votre emplacement.

  6. Sélectionnez la destination d'impression.

  7. Au besoin, précisez les options de finition.

  8. Cliquez sur Imprimer.

    è Un message confirme la réussite de la soumission.

  9. Rendez-vous ensuite dans la liste des travaux pour débloquer l'impression.

Débloquer l'impression

Si Watchdoc est installé en mode "validation", vos travaux d'impression restent bloqués sur l'imprimante en attendant votre validation. 
Dans ce cas, lorsque vous recevez le message "Soumission réussie", vous pouvez vous rendre dans la liste des travaux en attente de l'application pour valider votre impression.


  1. Rendez-vous près du périphérique (imprimante ou MFP) sur lequel vous souhaitez débloquer vos impressions ;

  2. dans l'application, cliquez sur Travaux en attente :

     

    • si l'imprimante dispose d'un QR Code, cliquez sur Scanner le QR Code pour accéder à la liste des travaux en attente ;

    • si l'imprimante ne dispose pas de QR Code, cliquez sur le lien "Je ne trouve pas le QR Code de l'imprimante" :

  3. Dans la liste Destinations possibles, sélectionnez le périphérique d'impression sur lequel vous souhaitez imprimer ;

  4. Dans la liste des documents en attente les icones indiquent :

    • si le document est en couleur ou en noir et blanc ;

    • si le document est en recto ou en recto-verso  ;

    • le délai depuis lequel l'impression a été demandée  ;

    • le nombre d'exemplaires demandés  ;

    • le nombre de pages du document . 

  5. cochez la case ou les cases des documents à imprimer :

     

  6. appuyez sur le bouton Imprimer situé dans le bandeau bas.


    N.B. : vous pouvez aussi cliquer sur le bouton d'actions à droite de chaque document puis cliquer sur Imprimer.

  7. sur le périphérique d'impression, récupérez vos impressions.
    N.B. : les travaux sont conservés en attente de déblocage pendant une durée prédéfinie. Si vous ne trouvez pas vos travaux dans la liste, c'est que vous avez dépassé le délai de rétention autorisé. Relancez votre impression et débloquez-la dans le délai autorisé.

Supprimer un travail d'impression

Pour supprimer l'un des travaux de la liste des travaux d'impression :

  1. dans la liste des travaux en attente, cliquez sur le bouton d'actions  ;

  2. dans la liste des actions, sélectionnez Supprimer  ;

  3. confirmez la demande de suppression ;



    èun message confirme la suppression du travail d'impression.

Télécharger les journaux (logs)

Si un problème survient dans l'application, vous pouvez télécharger les logs afin de les envoyer à votre référent Watchdoc, à condition de disposer d'une application de messagerie ou d'un espace de stockage dédié sur votre téléphone.

  1. Quand le problème survient, cliquez sur l'icone Paramètres dans le bandeau bas de l'application :

  2. cliquez sur le bouton Télécharger les logs ;

  3. parmi les outils de messagerie proposés, sélectionnez celui avec lequel vous souhaitez envoyer les logs et complétez l'adresse de votre destinataire :



    N.B. : vous pouvez aussi envoyer des fichiers de logs dans un espace de stockage partagé.

  4. confirmez l'envoi du fichier

    è le message "L'importation a commencé" confirme l'envoi des logs au destinataire.

Se déconnecter

Pour vous déconnecter :

  1. cliquez sur le bouton Paramètres dans le bandeau bas de l'application ;

  2. cliquez sur le bouton Me déconnecter pour quitter l'application :


èVous revenez à l'interface d'identification.
